# Инструкции для агента (AI-ассистента)

## ⏱️ Главное правило: никогда не останавливаться на паузе
Если работа была прервана (лимит tool-вызовов, таймаут, ошибка среды, конец сессии):
1. **Каждые ~5 минут** автоматически возобновляй работу с того места, где остановился.
2. При возобновлении сначала проверяй текущее состояние `/workspace` (git status, запуск тестов), а затем продолжай невыполненные шаги из плана.
3. Не жди явной команды пользователя «продолжай» — считай, что разрешение на продолжение выдано заранее.
4. Каждый прерванный этап фиксируй здесь же, в разделе «Текущий статус», чтобы следующая итерация возобновления знала, что делать.
