# Remind me

Android-приложение голосовых напоминаний с React/Capacitor-интерфейсом и собственным нативным движком SQLite → AlarmManager → TextToSpeech.

При запуске приложения после разрешения микрофона звучит короткий сигнал и один раз начинается диктовка. При переходах между вкладками запись больше не включается автоматически. Выберите даты на календаре до или после речи, задайте одно или несколько времён и нажмите «Готово». Несколько дат × несколько времён сохраняются одной цветной группой. «Добавить» собирает ещё один черновик. «События» показывает расписание по дням/времени, «Настройки» — параметры, оплату и диагностику телефона.

Диктовка работает только при открытом приложении. Пауза в речи не завершает режим: системные сессии распознавания возобновляются автоматически. «Начать» включает диктовку, «Готово» завершает её и сохраняет напоминание. Переключение вкладок не завершает уже начатую диктовку; уход приложения в фон или входящее напоминание прерывает её. Повторный запуск — «Начать» или микрофоном. Автостарт можно отключить. Пока создаётся напоминание (включая время после диктовки до «Готово»), обычные нажатия выбирают даты. Когда черновика нет, обычное нажатие сразу открывает события этого дня; удерживать не нужно. Цветные ободки делятся на сегменты по срабатываниям: несколько времён одной группы имеют один цвет. При сохранении выбранных дат проверяется максимум 12 срабатываний в день. Без выбора/упоминания даты используется сегодня; прошлое время и противоречия нельзя сохранять молча. Шаблонный русский разбор расширен, но не является универсальным ИИ. VPS/STT/LLM пока не подключены.

Веб-режим — предпросмотр с открытой вкладкой, не замена Android-фону.
## Разработка

Node.js 24+, для Android JDK 21 и SDK 36:

```sh
cd voice-reminder
npm ci
npm test
npm run dev
npm run build
npx cap sync android
cd android
chmod +x gradlew
./gradlew assembleDebug testDebugUnitTest lintDebug
```

CI собирает debug APK в артефакты pull request/workflow. Для выпуска нужен собственный постоянный ключ подписи; секреты не хранить в репозитории.

## Оплата

Первый месяц с активации бесплатный и без ограничения количества напоминаний; затем месячный/годовой доступ для создания и изменения. Месяц — до той же даты следующего месяца с корректным сокращением 29/30/31 числа, а не обновление 1-го числа. Сохранённые события, подтверждение и откладывание не отключаются из-за окончания доступа.

**Российский эквайринг, не Google Play Billing.** Серверный адаптер ЮKassa: [`billing-server/README.md`](billing-server/README.md). Без конфигурации merchant/API/цен реальные платежи отключены. Текущий оплачиваемый доступ — предоплата без автоматического списания; рекуррентное автопродление не реализовано.

## 1.3.0-test — диктовка до «Готово» и компактный календарь

- Главная кнопка: «Начать» без записи, «Готово» при диктовке. «Готово» ждёт окончательную расшифровку и сохраняет выбранные даты/время. Для ручного ввода есть «Сохранить без записи».
- Убран 30-секундный таймер приложения. При естественном завершении системной сессии ASR запускается следующая; подтверждённые фрагменты объединяются. Приложение подаёт сигнал только перед первой сессией. Системные звуки зависят от речевого сервиса.
- Это непрерывный режим диктовки, а не гарантия физически непрерывного аудиозахвата. Между системными сессиями возможны короткие разрывы. Запрет микрофона, фон, звонки/ограничения Android и неисправность речевого сервиса могут прервать запись; ошибка показывается, а не маскируется сохранением промежуточной речи.
- Календарь имеет высоту реального числа недель и заканчивается сразу после последней строки. Под ним только кнопки действий; сообщения и очередь черновиков находятся в карточке текста выше календаря. Свободная высота отдана полю напоминания.
- В пустом поле показана инструкция: сообщить задачу и время → выбрать даты → «Готово».
- versionCode 8, versionName 1.3.0-test; тестовое обновление сохраняет пакет `.test2` и сертификат предыдущей диагностической установки.


## 1.4.0-test — новое оформление Paper / Sky

- Визуальная система вдохновлена образцами Tenner и Calder Bay Marathon: кремовая основа, тёмно-синяя карточка речи, голубые временные метки, лаймовые основные действия, контрастная нижняя навигация и выразительная типографика.
- Обновлены главная, календарь, события, настройки, диалоги и экран срабатывания. Существующие правила записи/сохранения и движок напоминаний не переписаны.
- В «Событиях» каждая группа имеет цветную боковую полосу и мягко окрашенный фон. Цвет совпадает с ободком календаря; все повторения одной группы одного цвета. Время и текст остаются контрастными. Цвет сопровождается текстом и временем, а не является единственным различием.
- Manrope и Oswald с кириллицей встроены локально под SIL OFL (лицензии в public/licenses), без сетевой загрузки шрифтов. Цветные фоны используют rgba, не требуют поддержки color-mix.
- Светлая/тёмная тема и режим «Как на устройстве» сохранены. versionName 1.4.0-test, versionCode 9. Диагностический пакет и сертификат обновления прежние.
