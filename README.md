# Голосовая напоминалка

Приложение, которое понимает фразу, сказанную голосом, и напоминает о деле в
нужный момент. Работает в браузере и на Android.

Скажите: «Напомни завтра в половине десятого позвонить врачу» — приложение
распознаёт речь, разбирает дату и время из свободной формы, показывает
подтверждение и вовремя срабатывает: звуком, голосом и уведомлением.

## Запуск в браузере

```bash
cd voice-reminder
npm install
npm run dev
```

Откройте `http://localhost:5173`. Голосовой ввод работает в Chrome и Edge
(нужен доступ к микрофону); в остальных браузерах доступен ввод текстом или
демо-фразы.

## Тесты

```bash
npm test              # оба набора
npm run test:parser   # 42 случая разбора фраз
npm run test:scheduler # 23 случая времени и таймеров
```

## Сборка для Android

Одной командой APK не собрать: нужен Android SDK.

**В облаке (ничего ставить не надо):** запушьте репозиторий — воркфлоу
`.github/workflows/android.yml` соберёт APK и положит его в артефакты запуска.

**Локально:** понадобятся JDK 17+ и Android SDK.

```bash
cd voice-reminder
npm run build
npx cap add android     # один раз
npx cap sync android
cd android && ./gradlew assembleDebug
```

Подробности — в [ANDROID.md](voice-reminder/ANDROID.md).

## Чем Android отличается от браузера

Два механизма пришлось заменить, иначе приложение на телефоне не работало бы:

- **Напоминания.** В браузере это таймер страницы: закрыли вкладку —
  напоминание пропало. На Android используется системный `AlarmManager`,
  поэтому уведомление приходит даже при выгруженном приложении.
- **Речь.** В Android WebView `SpeechRecognition` не поддерживается, поэтому
  там работает нативный плагин распознавания.

Обе реализации живут за общими интерфейсами (`speech.js`, `alarm.js`), так что
остальной код о платформе не знает.
