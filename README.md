# Remind me

Android-приложение голосовых напоминаний с React/Capacitor-интерфейсом и собственным нативным движком SQLite → AlarmManager → TextToSpeech.

Откройте главную: после разрешения микрофона начинается диктовка. Выберите даты на календаре до или после речи, задайте одно или несколько времён и нажмите «Готово». Несколько дат × несколько времён сохраняются одной цветной группой. «Добавить» собирает ещё один черновик. «События» показывает расписание по дням/времени, «Настройки» — параметры, оплату и диагностику телефона.

Запись только при открытой главной; её можно остановить или отключить автоматическое включение. Без выбора/упоминания даты используется сегодня; прошлое время и противоречия нельзя сохранять молча. Шаблонный русский разбор расширен, но не является универсальным ИИ. VPS/STT/LLM пока не подключены.

Веб-режим — предпросмотр с открытой вкладкой, не замена Android-фону.
## Разработка

Node.js 24+, для Android JDK 21 и SDK 36:

```sh
cd voice-reminder
npm ci
npm test
npm run dev
npm run build
npx cap sync android
cd android
chmod +x gradlew
./gradlew assembleDebug testDebugUnitTest lintDebug
```

CI собирает debug APK в артефакты pull request/workflow. Для выпуска нужен собственный постоянный ключ подписи; секреты не хранить в репозитории.

## Оплата

Первый месяц с активации бесплатный и без ограничения количества напоминаний; затем месячный/годовой доступ для создания и изменения. Месяц — до той же даты следующего месяца с корректным сокращением 29/30/31 числа, а не обновление 1-го числа. Сохранённые события, подтверждение и откладывание не отключаются из-за окончания доступа.

**Российский эквайринг, не Google Play Billing.** Серверный адаптер ЮKassa: [`billing-server/README.md`](billing-server/README.md). Без конфигурации merchant/API/цен реальные платежи отключены. Текущий оплачиваемый доступ — предоплата без автоматического списания; рекуррентное автопродление не реализовано.
