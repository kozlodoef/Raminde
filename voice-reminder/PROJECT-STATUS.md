# Статус проекта

Текущая разработка версии 2: см. [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md).

Исторический аудит первоначального состояния приведён в корневом [PROJECT-TASK.md](../PROJECT-TASK.md). Старые Windows-пути, утверждения о конкретной локальной APK и количестве отслеживаемых node_modules больше не используются как актуальная инструкция.

Команды:

```sh
npm ci
npm test
npm run build
npx cap sync android
cd android
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Для сервера российского эквайринга: `cd billing-server && npm test` из корня проекта; см. его README. Реальные платежи до настройки магазина отключены.

## 1.1.0-test

Новая календарная главная, автоматический видимый микрофон, черновики, цветные группы дат/времён, хронологические события, адаптивная компоновка для планшетов и первый бесплатный месяц без лимита. Внутренний расширенный редактор применяет изменения к черновику; окончательное сохранение — «Готово». Сохранённые напоминания/настройки и рабочие receiver/AlarmClock сохранены. Серверный ИИ и реальный эквайринг не подключены. Новый APK обновляет диагностическую сборку с тем же applicationId и ключом; production-релиз требует отдельной подготовки.
